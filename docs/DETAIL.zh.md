# 坦克世界壁纸

把《坦克世界》官网的美术图铺在 DeepSeek Harness 网页界面背后，每天换一张。

## 做什么

- **图片来源**：官方媒体库（`worldoftanks.eu` 的壁纸标签）。只用官网发布的图，
  不打包图片，也不从第三方站点抓取。
- **每月最多下载一次**：宿主侧在启动时检查一次，界面请求状态时也顺带检查。
  如果上一批下载距今不到 30 天就完全不联网；失败后 1 小时内不重试，避免网络
  不稳时反复请求官网。
- **保留约 10 张**：从列表中按“坦克战场”优先挑出 10 张，优先 1920×1080，
  没有该尺寸时退回 2560×1440 等官方尺寸。宣传拼贴图和人物立绘排序靠后，
  所以图库基本是坦克场景。新批次落地后会删掉没被选中的旧文件。
- **每天换一张**：当天用哪张只由本地日期决定，因此每天本地零点自动换图，
  并且所有窗口看到的是同一张。控制条上的箭头只是调整顺序，不改变每日节奏。

## 文件位置

| | |
| --- | --- |
| 图片 | `$DSH_HOME/cache/wot-wallpaper/images/<slug>.jpg` |
| 状态 | `$DSH_HOME/cache/wot-wallpaper/state.json` |

`$DSH_HOME` 默认是 `~/.dsh`。整个目录可以直接删；下次刷新会重新下载一批。

## 控制条

窗口底部一条 26 像素高的控制条：

| 控件 | 作用 |
| --- | --- |
| `‹` / `›` | 看上一张 / 下一张（明天的每日轮换从新的偏移继续） |
| `⟳` | 立刻下载，忽略 30 天间隔 |
| `✕` | 关掉壁纸（保留已下载的图），之后控制条上会显示“开启” |

鼠标悬停在标题上可以看到图片名称和原始链接。

## HTTP 接口

由宿主侧在界面同源下提供，浏览器不需要额外权限：

| 路由 | 说明 |
| --- | --- |
| `GET /wot-wallpaper/state` | JSON：开关、图片列表、今日序号、最近错误 |
| `GET /wot-wallpaper/img/<id>` | JPEG/PNG 图片字节（浏览器缓存一周） |
| `POST /wot-wallpaper/action` | `{"action":"next" \| "prev" \| "refresh" \| "enable" \| "disable" \| "reset"}` |

## 说明与限制

- 官网欧洲区媒体库自 2023 年后没有再发布新壁纸，所以一次刷新可能仍然是同样
  十张。每月检查一次仍然是发现新图的最低成本方式。
- 图片画在窗口框架本身上，所有原本会挡住它的表面都改成半透明：左侧栏保留 40%
  底色并加 18px 背景模糊，右侧面板和输入框变毛玻璃，中间对话区在主题色遮罩上
  再加 2.5px 轻模糊。浅色和深色主题下文字都可读。
- 用的都是主题自己的表面色变量，换主题插件也不会串色，没有写死某套配色。
- 安装后需要重新加载一次页面（Ctrl+R）新的样式才会生效。
- 下载需要宿主能访问 `worldoftanks.eu`；连不上时控制条会显示错误，已下载的
  图片继续每天轮换。
